# Generics e utility types tipos que se adaptam

Snapshot do quiz **ao final** desta aula.

## O que entra aqui

shuffle<T>.

## Como rodar

```bash
npm install
npm start
```

(Quando houver testes: `npm test`. Com TypeScript: `npm run check`.)

Estado de referência interno: `quiz-passos/24-generics`.

Se existir `.env.example`, copie antes de rodar:

```bash
cp .env.example .env
```
