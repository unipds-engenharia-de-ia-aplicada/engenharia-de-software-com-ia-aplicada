# Testes nativos do node

Snapshot do quiz **ao final** desta aula.

## O que entra aqui

Dois testes com node:test.

## Como rodar

```bash
npm install
npm start
```

(Quando houver testes: `npm test`. Com TypeScript: `npm run check`.)

Estado de referência interno: `quiz-passos/20-testes`.

Se existir `.env.example`, copie antes de rodar:

```bash
cp .env.example .env
```
