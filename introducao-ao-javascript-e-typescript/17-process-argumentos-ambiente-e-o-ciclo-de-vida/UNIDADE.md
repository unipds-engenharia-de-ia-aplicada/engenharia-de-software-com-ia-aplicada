# Process argumentos ambiente e o ciclo de vida

Snapshot do quiz **ao final** desta aula.

## O que entra aqui

.env (QUIZ_TITLE) + --limit.

## Como rodar

```bash
npm install
npm start
```

(Quando houver testes: `npm test`. Com TypeScript: `npm run check`.)

Estado de referência interno: `quiz-passos/17-process`.

Se existir `.env.example`, copie antes de rodar:

```bash
cp .env.example .env
```
