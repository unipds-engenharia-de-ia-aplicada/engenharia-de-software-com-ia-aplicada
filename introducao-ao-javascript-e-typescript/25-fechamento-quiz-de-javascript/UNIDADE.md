# Fechamento quiz de javascript

Snapshot do quiz **ao final** desta aula.

## O que entra aqui

Estado final do quiz (TypeScript).

## Como rodar

```bash
npm install
npm start
```

(Quando houver testes: `npm test`. Com TypeScript: `npm run check`.)

Estado de referência interno: `quiz-passos/26-final`.

Se existir `.env.example`, copie antes de rodar:

```bash
cp .env.example .env
```
