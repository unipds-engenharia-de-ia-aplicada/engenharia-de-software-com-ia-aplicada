# A biblioteca padrao do node node

Snapshot do quiz **ao final** desta aula.

## O que entra aqui

fetch do Gist + URL/timeout no .env.

## Como rodar

```bash
npm install
npm start
```

(Quando houver testes: `npm test`. Com TypeScript: `npm run check`.)

Estado de referência interno: `quiz-passos/19-fetch-gist`.

Se existir `.env.example`, copie antes de rodar:

```bash
cp .env.example .env
```
