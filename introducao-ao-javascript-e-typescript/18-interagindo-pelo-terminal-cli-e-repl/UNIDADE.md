# Interagindo pelo terminal cli e repl

Snapshot do quiz **ao final** desta aula.

## O que entra aqui

Quiz interativo com readline.

## Como rodar

```bash
npm install
npm start
```

(Quando houver testes: `npm test`. Com TypeScript: `npm run check`.)

Estado de referência interno: `quiz-passos/18-readline`.

Se existir `.env.example`, copie antes de rodar:

```bash
cp .env.example .env
```
