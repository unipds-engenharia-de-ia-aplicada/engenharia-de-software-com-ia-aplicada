# Modelando dados type interface e unioes

Snapshot do quiz **ao final** desta aula.

## O que entra aqui

types.ts (Question, QuizInteraction) + anotações.

## Como rodar

```bash
npm install
npm start
```

(Quando houver testes: `npm test`. Com TypeScript: `npm run check`.)

Estado de referência interno: `quiz-passos/23-types`.

Se existir `.env.example`, copie antes de rodar:

```bash
cp .env.example .env
```
