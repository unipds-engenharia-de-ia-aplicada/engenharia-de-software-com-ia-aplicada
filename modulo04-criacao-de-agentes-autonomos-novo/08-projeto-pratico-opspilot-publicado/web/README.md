# OpsPilot War Room

SPA Vite + React + TypeScript para o plantão: chat com o agente, “Ver raciocínio” (trace tipado), cartão de aprovação (HTTP 202) e configuração da URL da API.

Documentação do projeto, Pages e API: ver o [README raiz](../README.md).

## Dev

```bash
npm run web:dev      # http://localhost:5173/opspilot/
npm run web:build
npm run web:test
```

Build alinhado ao GitHub Pages:

```bash
npm run build -- --base=/ops-pilot/
```
