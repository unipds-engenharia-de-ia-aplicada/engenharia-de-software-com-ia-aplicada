# System design de IA

Material dos vídeos de system design. Para abrir os arquivos `.excalidraw`, acesse [excalidraw.com](https://excalidraw.com) e arraste o arquivo para a página (ou use *Open*).

## Caso da aula: assistente de atendimento com RAG

- [`rag-assistant-problem.excalidraw`](./rag-assistant-problem.excalidraw): só o enunciado. Tente resolver antes de ver a solução.
- [`rag-assistant-solution.excalidraw`](./rag-assistant-solution.excalidraw): perguntas e respostas, requisitos, estimativas, arquitetura, trade-offs, modos de falha e perguntas de follow-up.

## Exercícios

Cada exercício tem um enunciado vago, seis etapas com perguntas (requisitos, dados, arquitetura, avaliação, custo e latência, riscos), uma área para desenhar e, no fim, as respostas do entrevistador. Consulte as respostas só depois de fazer a pergunta.

| Arquivo | Enunciado |
|---|---|
| [`01-meeting-summary`](./exercises/01-meeting-summary.excalidraw) | Projete um sistema que resume reuniões. |
| [`02-sales-email-assistant`](./exercises/02-sales-email-assistant.excalidraw) | Projete um assistente que ajude o time de vendas a responder e-mails de clientes. |
| [`03-ticket-classification`](./exercises/03-ticket-classification.excalidraw) | Projete um sistema que organize os tickets de suporte de uma empresa. |
| [`04-catalog-search`](./exercises/04-catalog-search.excalidraw) | Projete uma busca melhor para o catálogo de um e-commerce. |
| [`05-appointment-scheduling`](./exercises/05-appointment-scheduling.excalidraw) | Projete um assistente que agende consultas para uma rede de clínicas. |

Se a resposta que você precisa não estiver no quadro, assuma algo razoável e diga em voz alta o que assumiu.
