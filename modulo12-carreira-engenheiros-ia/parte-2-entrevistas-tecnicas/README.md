# Parte 2: Entrevistas técnicas

Código e exercícios dos vídeos de entrevista técnica para engenheiros de IA aplicada.

| Pasta | Vídeo | Conteúdo |
|---|---|---|
| [`01-live-coding-duplicates`](./01-live-coding-duplicates/) | Live coding: como funciona a entrevista | Exemplo curto para praticar o método de seis passos |
| [`02-live-coding-set-game`](./02-live-coding-set-game/) | Live coding: o jogo Set | Exercício em 4 níveis com orientação a objetos e testes |
| [`03-system-design`](./03-system-design/) | System design de IA | Caso do assistente com RAG (problema e solução) e 5 exercícios |

Os projetos de código usam Node.js 18 ou mais novo e não têm dependências. Em cada pasta, rode `npm test` para testar o seu código e `npm run test:solution` para testar a solução de referência.
